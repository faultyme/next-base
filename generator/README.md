# @faultyme/next-base

A minimal Next.js + TypeScript project generator with an optional database bundle.

## Usage

Run:

npx @faultyme/next-base my-app

The generator will ask whether you want to include the Database bundle.

## Bundles

### Core

Always included:

- Next.js
- React
- TypeScript
- Tailwind CSS
- ESLint
- Prettier
- Husky
- lint-staged
- Commitlint
- Basic project architecture
- Public API route convention

### Database

Optional. Includes:

- Neon PostgreSQL
- Drizzle ORM
- Drizzle Kit
- Zod validation
- Example API routes
- Bruno API collection
- Database configuration

Database migrations are generated by the project after creation.

## Requirements

- Node.js 20 or newer

## Package

Published under the @faultyme npm scope.
